# 0006 AI Usage and Disclosure

## Course rule

AI may be used for brainstorming, code assistance, testing, analysis, and drafting. The team remains responsible for the final design, implementation, scientific interpretation, and report. AI-generated text is a draft and never constitutes experimental evidence.

## Team policy

For every material use of AI:

1. A team member reviews and owns the result.
2. Technical and scientific claims are verified through code review, tests, primary sources, or retained experiment evidence.
3. Generated code receives the same tests and peer review as human-written code.
4. Generated prose is checked and rewritten in the team’s own style.
5. Material assistance is disclosed in the relevant pull request.
6. No confidential, personal, or restricted information is submitted to an external AI service.
